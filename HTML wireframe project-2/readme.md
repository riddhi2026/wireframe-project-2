Pure Bicycle Website 🚲
📌 Project Overview

Pure Bicycle is a bicycle shopping website built using HTML. It showcases featured bicycles, bicycle accessories, product prices, promotional images, videos, and contact information in a simple and organized layout.

✨ Features
Featured Bikes: Displays bicycles with product names, images, and prices.
Shop by Category: Showcases bicycle accessories such as security locks, helmets, and bags.
Our Videos: Includes a video section for bicycle-related content.
Promotional Banner: Displays lifestyle images related to cycling.
Footer Section: Provides shopping links, contact information, company details, and support information.
Email Signup: Includes an email input field for newsletter subscriptions.
🛠️ Technologies Used
HTML5
External image resources
HTML tables for layout
HTML forms and buttons
Embedded media

🚀 How to Run the Project
Download or clone the project repository.
Open the project folder.
Open index.html in any modern web browser.
Browse the featured bicycles, categories, video section, and footer.

No additional software installation is required.
